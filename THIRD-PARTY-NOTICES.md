# Third party notices

Printendar redistributes the following third party material.

## Noto Sans

Printendar embeds Noto Sans (Regular and SemiBold, unhinted TTF) in `Printendar.Core` and
uses it as the default layout font. Embedding rather than using a system font is what makes
a month lay out identically on Windows, macOS and Linux.

- Source: https://github.com/notofonts/notofonts.github.io
- Copyright: The Noto Project Authors
- License: SIL Open Font License, Version 1.1

The full license text ships alongside the font files at `assets/fonts/OFL.txt`.

## SkiaSharp

Printendar uses SkiaSharp for text measurement, rendering and PDF export.

- Source: https://github.com/mono/SkiaSharp
